# STAR PATROL · 星际巡航

一个复古像素风的纵向飞机大战，使用 HTML5、CSS3、原生 JavaScript 和 Canvas 2D API 编写。

## 运行

下载或克隆仓库，保持 `index.html`、`style.css` 和 `game.js` 在同一个目录，双击 `index.html` 即可在现代桌面浏览器运行。无需安装依赖、构建工具、服务器或运行环境；支持离线和 `file://`，不使用 fetch、外部图片、字体、CDN 或其他远程资源。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | 方向键或 WASD |
| 连续射击 | 按住空格 |
| 暂停 / 继续 | P 或页面按钮 |
| 开始 / 重新开始 | 页面按钮 |

玩家初始有 3 条生命；击落每架敌机获得 100 分。碰撞消耗 1 条生命，并提供 1.6 秒闪烁无敌时间。敌机飞出底部不会扣血。敌机随时间逐渐加速、生成更频繁，生命归零后显示 Game Over 和最终得分。切换标签页或窗口失焦时自动暂停，返回后手动继续。

## 文件

- `index.html`：入口、分数与生命面板、游戏控制按钮。
- `style.css`：居中布局、响应式尺寸、复古街机外观。
- `game.js`：输入、requestAnimationFrame 循环、碰撞、粒子和全部 Canvas 图形。
- `README.md`：运行与操作说明。

Canvas 内部分辨率为 480 × 720，窄屏等比例缩放。使用键盘游玩，暂不提供触屏控制。游戏不保存分数，也不发送网络请求。
